# Korean vocabulary study

I am learning Korean. My study questions are in the questions/ folder.

When I give you one or more Korean words, or an Korean phrase containing both vocabulary and grammar:
1. Search all files in questions/ for each word.
2. Korean words change form with particles and verb endings (for example 먹다 can appear as 먹어요, 먹었어요, 먹고).
   Search using the word stem so you also find these variations.
3. For each match, show the file name, the full sentence containing that specific word. If there are more than one sentence containing that word, just pick a random sentence among those available sentences.
4. Add the word to vocabulary.md with its meaning, and its number in the list. Skip it if it is already there. Note if that word is a noun (n), a verb (v), etc. Number the words, do not start them with a bullet point or a hyphen.
For example: 1. 먹다 (v) to eat
5. If there is a grammar point available in the phrase i provided, create grammar.md with its usage, and its number in the list. Skip it if it is already there. Number the grammar points, do not start them with a bullet point or a hyphen.
Keep explanations short and clear. Use English for explanations.
